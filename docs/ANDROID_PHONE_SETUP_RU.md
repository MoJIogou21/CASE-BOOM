# CASE BOOM — инструкция для разработки только с Android-телефона

## Почему используем облачную сборку
Полноценная локальная установка Flutter SDK и Android SDK на обычный Android-телефон неудобна и часто несовместима. Поэтому телефон будет использоваться для редактирования и управления проектом, а GitHub Actions — для сборки APK в облаке.

## Шаг 1. Подготовь аккаунты и приложения
1. Создай аккаунт GitHub: https://github.com
2. Установи Acode из Google Play или используй другой редактор файлов.
3. Открой браузер Chrome на телефоне.
4. Скачай и распакуй `CASE_BOOM_starter.zip` на телефоне.

## Шаг 2. Создай репозиторий
1. На GitHub нажми `+` → `New repository`.
2. Назови репозиторий `case-boom`.
3. Выбери `Public` или `Private` и создай репозиторий.
4. Открой репозиторий → `Add file` → `Upload files`.
5. Загрузи содержимое папки проекта, сохранив структуру каталогов.
6. Нажми `Commit changes`.

Важно: загружай содержимое папки проекта, а не ZIP-файл как один файл.

## Шаг 3. Запусти автоматическую сборку APK
1. В репозитории открой вкладку `Actions`.
2. Найди workflow `Build Android APK`.
3. Нажми `Run workflow`, если он не стартовал после загрузки.
4. Дождись зелёной галочки.
5. Открой завершённый запуск workflow.
6. Внизу страницы скачай артефакт `case-boom-debug-apk`.
7. Распакуй скачанный ZIP и установи APK на Android.
8. Если Android спросит разрешение на установку из этого источника, разреши его только для браузера/файлового менеджера, которым скачивал APK.

## Шаг 4. Как вносить изменения
- Для правок можно использовать Acode и затем загружать изменённые файлы в GitHub.
- Для небольших правок GitHub также позволяет открыть файл, нажать карандаш, изменить код и сохранить через `Commit changes`.
- Каждое сохранение в ветку `main` автоматически запускает сборку APK.

## Что должно получиться
На первом этапе проверяем:
- приложение запускается;
- видны вкладки «Кейсы», «Инвентарь», «Магазин», «Профиль»;
- открывается экран кейса;
- рулетка прокручивается и останавливается;
- выигранный демо-предмет появляется в инвентаре.

## Если сборка не проходит
1. Открой `Actions`.
2. Выбери красный запуск.
3. Открой шаг с ошибкой.
4. Скопируй последние 30–50 строк ошибки и отправь их в ChatGPT.
Не удаляй файлы проекта и не меняй версии SDK наугад.

## Ограничения текущего прототипа
- Рулетка и награды пока демонстрационные.
- Магазин начисляет виртуальные монеты локально, без платежей.
- Данные пока не сохраняются после закрытия приложения.
- API пока не выдаёт предметы: серверная транзакционная логика будет следующим этапом.
- Нельзя использовать чужие игровые изображения, логотипы или модели без необходимых прав.
